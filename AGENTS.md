# FSV Algermissen v3

Dieses Repository enthaelt die neue Cloudflare/Astro-Edition der Website fuer den gesamten FSV Algermissen.

## Arbeitsregeln

- Der Verein steht als Ganzes im Mittelpunkt: Herren, Senioren, Jugend/JSG Nord, Darts, Vorstand, Vereinsleben und Sponsoren.
- Keine Secrets, Passwoerter oder Cloudflare IDs committen.
- Inhalte werden datengetrieben aufgebaut, damit D1/CMS spaeter ohne kompletten Umbau uebernehmen kann.
- FUSSBALL.DE Widget-IDs werden zentral gepflegt und nie direkt in Komponenten verteilt.
- Cloudflare D1 Migrationen bleiben versioniert unter `migrations/`.

## Milestone 1 Fokus

- Astro + Cloudflare Grundlage.
- Zentrale News-Seite mit Mehrfachzuordnung.
- Struktur fuer alle Teams, Jugend und Darts.
- Admin-Login und News-Verwaltung als belastbares Grundgeruest.
- Dokumentierte Annahmen fuer die spaetere Migration.
